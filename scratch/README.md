# scratch

Project-local scratch area. Nothing here is a deliverable, but every input that
produced a logged result lives here rather than in a session temp directory.

| # | Path | Contents | Tracked |
|---|------|----------|---------|
| 1 | `ptt_bodies/ptt_<standard>.rs` | the test bodies of `rust_verify_test/tests/standards/Prove<standard>.rs`, copied as plain modules so `scripts/validate-standard.sh <standard> deps ptt` can verify them against the standard without the nightly PTT harness | yes |
| 2 | `harness-<name>/lib.rs` | crate roots generated by `scripts/validate-standard.sh`; regenerated on every run | no (gitignored) |
